# Student Project Repositories

Historical Technion student projects supervised by Aaron Wetzler. Each project has a separate repository so its original authors can contribute updates or request corrections or removal.

Eleven repositories contain reviewed original source or a pinned public upstream, four contain recovered documents without verified app source, and eight currently contain only an introductory README. Historical code is not a tested modern release. Consult each README for missing dependencies and the exact recovery status; a source link does not imply a complete, runnable application.

## Source and Attribution

Public original code is pinned as a Git submodule in OpenFusion, HeartBeat, Freehand Voxel Carving and Predator for iOS. Clone those repositories with `--recurse-submodules`. Other recovered code is stored under `source/`. Original student credits, existing notices and third-party terms are retained; this directory does not assign a blanket code license.

Privately recovered SDK binaries, signing material, private deployment values, personal records and raw submission archives are not published. Two QRoom database configuration files were sanitized to use environment variables. All other imported private-source files retain their original bytes. Reports and slides are linked separately from source availability.

The [homepage](https://twerdster.github.io/#projects) links project-specific code, reports, posters, demonstrations and original laboratory pages where available. The machine-readable [site index](data/site-content.json) records `repository`, `source_status`, `resources`, and pinned upstream revisions where applicable.
