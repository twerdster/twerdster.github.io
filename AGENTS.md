# Website editing guide

Read `README.md`, `data/site-content.json`, and `llms.txt` before editing this site.

## Content rules

- Keep the public page factual and academic in tone.
- Do not add marketing language, calls to action, visible TODOs, or placeholder sections.
- Ground historical claims in `archive.html` or source material supplied by Aaron.
- Prefer direct links to papers, BibTeX, code, datasets, posters, slides, and videos.
- Keep `index.html`, `data/site-content.json`, and `llms.txt` synchronized when resources change.
- Add CameraAI or Apple work only when approved text and public media or article links are available.

## Local command

```sh
npm run dev
```
